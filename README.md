# Furniture Business Website

A professional furniture business website designed to give customers an easy way to discover furniture products, view product information and prices, and learn more about the business.

The platform focuses on building a strong online presence for a local furniture business rather than providing a traditional e-commerce checkout experience.

## Features

- Furniture product showcase
- Product images and detailed information
- Product pricing display
- Business information and contact details
- Responsive design for mobile, tablet, and desktop
- Organized product presentation
- Content management for published furniture information
- SEO-friendly page structure
- Production-ready deployment

## Purpose

The website provides a digital storefront and information platform for the furniture business.

Customers can browse available furniture, learn about products, view prices, and find information needed to contact or visit the business.

The platform is intentionally focused on **product discovery and business visibility** rather than online checkout and order processing.

## Getting Started

### Prerequisites

Make sure you have the required development tools installed for the technologies used by the project.

### Clone the repository

```bash
git clone https://github.com/yemizerfe/FineFurniture.git
cd <project-directory>
```

### Install dependencies

```bash
npm install
```

### Environment Variables

Create a local `.env` file containing the environment variables required by the application.

Never commit `.env` files, passwords, API keys, database credentials, or other sensitive information to the repository.

### Run the application

```bash
npm run dev
```

The application will start in development mode.
